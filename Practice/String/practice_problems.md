### Level 1 — Basic String

1. Find the length of `"AutomationTesting"`.
2. Print the character at index `5` using `charAt()`.
3. Count the vowels in `"Automation"`.
4. Convert `"selenium testing"` to uppercase.

### Level 2 — Comparison & Checking

1. Compare expected and actual login messages using `equals()`.
2. Compare `"PASS"` and `"pass"` using `equalsIgnoreCase()`.
3. Check whether `"Payment Successful"` contains `"Successful"`.
4. Check whether `"https://example.com/login"` starts with `"https://"`.

### Level 3 — Extracting & Searching

1. Extract `"12345"` from `"ORD12345"` using `substring()`.
2. Find the position of `@` in `"ramesh@gmail.com"` using `indexOf()`.
3. Find the last `.` in `"ramesh.test@gmail.com"` using `lastIndexOf()`.
4. Extract `"gmail.com"` from `"ramesh@gmail.com"`.

### Level 4 — Cleaning & Replacing

1. Remove leading/trailing spaces from `"   Ramesh   "` using `trim()`.
2. Replace `"FAILED"` with `"PASSED"` in `"Test FAILED"`.
3. Remove all spaces from `"Java Automation Testing"`.
4. Remove all numbers from `"ABC123XYZ456"` using `replaceAll()`.

### Level 5 — `split()`

1. Split `"Ramesh,Java,Selenium,TestNG"` and print each value.
2. Count the number of values in `"Chrome,Firefox,Edge,Safari"`.
3. Split `"Login,Search,Cart,Checkout,Payment"` and print each module using enhanced `for`.
4. Split `"username=Ramesh,password=Test@123,status=PASS"` and print each part.

### Level 6 — `matches()`

1. Check whether `"9876543210"` contains only numbers.
2. Check whether `"Ramesh"` contains only alphabets.
3. Validate whether `"ORD12345"` follows `ORD + numbers`.
4. Validate a basic email format such as `"ramesh@gmail.com"`.

### Level 7 — Real Automation Testing 🔥

1. Compare expected vs actual login message, ignoring case.
2. Validate an actual Order ID such as `"ORD20260910"`.
3. Verify that a URL starts with `https://` and contains `/products/`.
4. Check whether `"Error: Invalid username or password"` contains all three expected keywords.

**We'll stay at one level at a time.** Start with **Level 1**, and once you're comfortable, we'll move to Level 2.
