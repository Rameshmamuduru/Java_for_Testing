### String methods

#### 🔴 Must Master

| #  | Method               | What you use it for                |
| -- | -------------------- | ---------------------------------- |
| 1  | `length()`           | Check string length                |
| 2  | `charAt()`           | Get a character at an index        |
| 3  | `equals()`           | Compare strings exactly            |
| 4  | `equalsIgnoreCase()` | Compare strings ignoring case      |
| 5  | `contains()`         | Check whether text exists          |
| 6  | `startsWith()`       | Verify beginning of text           |
| 7  | `endsWith()`         | Verify ending of text              |
| 8  | `isEmpty()`          | Check whether string is empty      |
| 9  | `isBlank()`          | Check empty/whitespace-only string |
| 10 | `substring()`        | Extract part of a string           |
| 11 | `indexOf()`          | Find first occurrence              |
| 12 | `lastIndexOf()`      | Find last occurrence               |
| 13 | `toUpperCase()`      | Convert to uppercase               |
| 14 | `toLowerCase()`      | Convert to lowercase               |
| 15 | `trim()`             | Remove leading/trailing spaces     |
| 16 | `strip()`            | Remove leading/trailing whitespace |
| 17 | `replace()`          | Replace characters/text            |
| 18 | `replaceAll()`       | Replace using regular expression   |
| 19 | `split()`            | Split string into multiple parts   |
| 20 | `concat()`           | Join strings                       |

#### 🟡 Important to Know

| #  | Method                  | What you use it for                                |
| -- | ----------------------- | -------------------------------------------------- |
| 21 | `matches()`             | Validate a string against regex                    |
| 22 | `replaceFirst()`        | Replace first matching occurrence                  |
| 23 | `join()`                | Join multiple strings with a delimiter             |
| 24 | `valueOf()`             | Convert values to String                           |
| 25 | `toCharArray()`         | Convert String to character array                  |
| 26 | `compareTo()`           | Compare strings lexicographically                  |
| 27 | `compareToIgnoreCase()` | Compare ignoring case                              |
| 28 | `format()`              | Create formatted strings                           |
| 29 | `contains()`            | Frequently used for partial text verification      |
| 30 | `getBytes()`            | Convert String to bytes when handling encoded data |
