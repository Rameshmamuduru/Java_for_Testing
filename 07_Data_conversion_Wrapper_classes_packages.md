**1. Wrapper Classes**

- A wrapper class is a Java class that represents a primitive data type as an object.

| Wrapper Class | Wrapper for Primitive |
| ------------- | --------------------- |
| `Byte`        | `byte`                |
| `Short`       | `short`               |
| `Integer`     | `int`                 |
| `Long`        | `long`                |
| `Float`       | `float`               |
| `Double`      | `double`              |
| `Character`   | `char`                |
| `Boolean`     | `boolean`             |
